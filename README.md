# Lead Predictor

A calculator that predicts how many prospects, leads and customers a campaign
needs in order to hit a revenue target, based on average order value and
response rates.

## Formulas

1. **Customers** = Total Revenue / Average Order Value
2. **Leads** = Customers * 100 / Lead Response Rate
3. **Prospects** = Leads * 100 / Prospect Response Rate

## Running locally

Just open `index.html` in a browser

## Deployment

The app is a static site (HTML/CSS/JS, no build step) and is deployed to
Netlify.
